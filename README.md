## 🛠️ Tecnologias Utilizadas

### Frontend & Animações
- **React 19** – Biblioteca para interfaces reativas e modulares
- **Vite** – Bundler moderno com inicialização instantânea e HMR
- **Framer Motion** – Animações fluidas de entrada, layout e micro-interações
- **Modern CSS** – Design system customizado em Vanilla CSS com estética Dark Mode, Glassmorphism e responsividade fluida
- **React Icons & Iconify** – Conjunto de ícones vetoriais modernos

### Integrações & APIs
- **@emailjs/browser** – Envio de mensagens direto pelo formulário de contato com feedback visual
- **GitHub REST API** – Consumo em tempo real dos últimos repositórios e projetos atualizados

## 📂 Seções do Portfólio

1. **Hero**: Destaque profissional com badges dinâmicos, métricas rápidas e botões de ação (CTA).
2. **Sobre Mim**: Perfil detalhado com foto, credenciais acadêmicas e diferenciais técnicos.
3. **Tecnologias**: Vitrine com filtro por categorias (Frontend, Backend & Dados, Ferramentas & IDEs).
4. **Soluções & Serviços**: Apresentação de serviços especializados (SaaS via WhatsApp, Web, Desktop em C# e APIs).
5. **Projetos**: Catálogo com filtros de navegação, tags de stack (TypeScript, PostgreSQL, C#, PHP), destaques e links diretos.
6. **Currículo & Atividade GitHub**: Download de CV em Português e Inglês (PDF) e feed de repositórios com proteção de fallback.
7. **Contato**: Formulário com validação, estado de carregamento e atalhos diretos para WhatsApp e e-mail.

## 💻 Como Rodar o Projeto Localmente

### Pré-requisitos
- Node.js (versão 18 ou superior)
- Git

### Instalação

```bash
# Clone o repositório
git clone https://github.com/leonardobier/portfolio.git

# Acesse o diretório
cd portfolio

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173) no seu navegador para visualizar.

### Build de Produção

```bash
npm run build
```
